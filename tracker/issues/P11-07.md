# [P11-07] Consolidate independent evaluation and uncertainty

**Topic:** `P11-07` · **Phase:** 11 (Week 24) · **Type:** experiment · **Effort:** ~5 h · **Compute:** hybrid

> **Completion rule:** close this GitHub issue only after checking every task, committing the required evidence, and linking the relevant commit or pull request. A failed experiment may pass **when its failure is reproduced, measured, and explained**. An optional stretch issue may be closed as *deferred* only with an explicit resource/budget rationale.

### Goal
Consolidate independent evaluation and uncertainty. Demonstrate practical command of this part of **Capstone and research portfolio** rather than merely completing a tutorial.

### Concepts to be able to explain
- Per-item paired comparisons
- confidence bands
- safety regressions
- failure taxonomy and cost

- [ ] Include slices, calibration limits and uncertainty

- [ ] I documented one unexpected finding, caveat, error mode, or alternative explanation; if none occurred, I explain why.
